# 因数分解 学習管理アプリ v2

## できること
- 先生側で5/10/15/20問を自動作成
- 問題と正解を編集
- 問題セットをブラウザに保存
- 保存した問題セットの再利用
- 生徒側でiPadに手書き
- 手書きの各ストロークを記録
- 認識結果欄を確認・修正して正誤判定
- 生徒ごとの結果を記録
- Firebase接続時は問題セットと答案をFirestoreへ保存

## GitHub Pagesへの公開
このフォルダのファイルをGitHubリポジトリのmainブランチへアップロードし、GitHub Pagesを有効にします。

## Firebase接続
1. Firebase Consoleでプロジェクトを作成
2. Webアプリを登録
3. `firebase-config.js` の値を自分のプロジェクトの設定に置き換える
4. Firestore Databaseを作成
5. Security Rulesを設定
6. GitHub Pagesへ再公開

## 重要
現在のバージョンでは、手書き文字そのものを高精度に数式OCRする外部APIは接続していません。
そのため「認識結果（確認・修正可）」へ数式を入力して判定できます。

本番版では次の段階として、数式OCR APIまたは専用の手書き数式認識モデルを接続し、
各行の途中式を数式として解析して数学的同値性を判定します。
